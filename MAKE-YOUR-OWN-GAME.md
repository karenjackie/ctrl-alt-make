# MAKE YOUR OWN GAME

Copy this prompt into ChatGPT:

## STARTER PROMPT

I want to make a 4×4 category game with you. My theme is [YOUR OBSESSION]. Let's design it together.

I want 16 tiles hiding four groups of four, with enough overlap to make the connections clever. Help me create and test the puzzle first. Make sure every tile is recognizable, every connection is defensible, and validate all four groups before we play. 

Don't reveal the answers while I'm playing. Once we like the game, help me turn it into a playable HTML version I can share.

## THEN KEEP GOING

Play it. Break it. Change the rules. Change the look. Tell ChatGPT what you like and what you don't. When it feels like yours, ask for the HTML version.
